Folio Reader

Read, share and print PDFs.

Download for Android Open in the browser

On an Android phone

  1. Tap Download for Android. If Chrome warns you about the file, tap Download anyway.
  2. Open the download and tap Install. If asked, allow Chrome to install apps.
  3. Open any PDF, choose Folio Reader, then tap Always.

On a Windows computer

  1. Click Open in the browser. It works best in Chrome or Microsoft Edge.
  2. To install it as an app, click the install icon at the right end of the address bar, then Install.
  3. To open a PDF with it, right-click the PDF, choose Open with, then Folio Reader.
